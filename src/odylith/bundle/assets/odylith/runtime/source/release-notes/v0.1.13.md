# Cross-Host Greenfield Intelligence and Runtime Integrity

Odylith v0.1.13 focuses on the consumer-lane experience: the runtime should be
fast, accurate, and helpful even before a repo has application source. A vague
request such as "build an ecommerce site" no longer dead-ends at missing source
evidence. Odylith can now draft a proposal first, label source posture and
assumptions explicitly, and wait for confirmation before writing governed truth.

The greenfield path is host-agnostic and provider-free by default. It uses a
deterministic domain-intelligence catalog for common software, infrastructure,
science, math, notebook, simulation, proof, data, AI, education, and instrument
workflows. The shipped catalog is the v0.1.13 built-in seed pack; the runtime API
is catalog-shaped so future signed or marketplace domain packs can compose
through the same scoring, metadata, and proposal compiler without moving
correctness into Claude, Codex, or any other host prompt.

This release also tightens the runtime integrity work behind that UX. Startup and
Context Engine order are kept serial and explicit, hooks stay quieter on success,
Compass can record accepted proposal memory, Casebook labels stay compact, Radar
topology is treated as a first-class spine, and migration gates now cover the
0.1.13 consumer-surface changes.

- `odylith show` in an empty repo now points to greenfield proposal mode instead
  of treating missing source as a dead end.
- `odylith greenfield propose` returns backlog, program waves, release plan,
  planned components, Atlas drafts, validation strategy, assumptions, and exact
  apply commands without provider calls.
- `odylith greenfield apply --confirm` writes only after confirmation, creates
  planned components and draft diagrams, assigns the selected release, and logs
  accepted intent into Compass memory.
- Science and math prompts receive domain-specific validation obligations such as
  units, tolerances, theorem-checker proof, reproducible notebooks, benchmark
  datasets, reference outputs, and peer-review artifacts without inventing
  scientific claims.
- Consumer and maintainer lanes keep separate host assets and guidance. Codex and
  Claude use native hooks and skills where useful, but the core proposal logic
  lives in the Odylith runtime and CLI.
- The local release bundle now carries a matching `0.1.13` wheel, version truth,
  security posture, managed assets, and migration markers for fresh install and
  upgrade proof.
