# Governed Execution Goes Multi-Host

Odylith v0.1.11 moves the product from Codex-first dogfood toward a real
multi-host governed execution layer. Claude Code now runs through the same
Odylith contract, the Context Engine and Execution Engine feed one action
loop, and release proof has benchmark coverage for the decisions that matter.

The release is still about proof without drift. The difference is scale: Odylith
now has host-aware execution, credit-safe discipline, and stronger benchmark
families behind the product surfaces users see.

- Claude Code is first-class. Project guidance, CLI-backed hooks, statusline
  and pre-compact context, skills, host capability detection, and execution
  semantics now share one governed path across Claude Code and Codex without
  pretending the two hosts have identical native capabilities.
- Governed execution is real now. Context Engine, Execution Engine, and
  Discipline connect task contracts, admissibility checks, frontier extraction,
  destructive-action blocking, receipts, resumability, validation matrices,
  credit-safe hard laws, and a compact learning spine.
- Benchmarks got teeth. Context grounding, execution policy, discipline,
  guidance behavior, and visible intervention all gained stronger
  product-contract scenarios, host-aware checks, and release gates that fail
  closed when proof is stale or ambiguous.
