Claude Code note: when you call `odylith backlog create`, use the exact CLI
enum tokens from `--help`. For backlog estimates, `--sizing` is one of
`XS`, `S`, `M`, `L`, `XL`, and `--complexity` is one of `Low`, `Medium`,
`High`, `VeryHigh`. Do not translate these into prose words such as
`small`, `medium`, or `moderate`.
