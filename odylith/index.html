47 workflows ready

Release planning has two steps: create the target release, then assign workstreams to it. Program/wave planning picks execution order under one umbrella, like `B-021 -> W1, W2, W3`. A workstream can belong to a release and a program wave at the same time. Replace the names and ids; when a prompt names a component like example-component or a workstream id like B-025, Odylith scopes to the tied files and governed records.
