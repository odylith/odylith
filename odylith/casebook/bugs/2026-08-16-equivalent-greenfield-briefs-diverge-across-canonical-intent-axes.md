- Reproducibility: Always

- Type: Product

- Description: Metamorphic paraphrases all complete successfully yet equivalent source facts produce different canonical stories, state objects, paths, human actors, dependencies, constraints, and internal-system axes. Sixteen aggregate findings are genuine pre-render product drift.

- Impact: A proposal can pass per-case term and custody gates while changing ownership, state-transition subject, visible-result placement, or dependency classification solely because the same intent is formatted differently.

- Components Affected: domain-intelligence

- Environment(s): 0.1.15 exact installed disclosed-v3 replay from commit 987814a75

- Detected By: Installed metamorphic aggregate output gate and retained semantic snapshots

- Failure Signature: Accent promotes Entry and Blue as human actors and moves résumé note instead of café entry; handoff loses claim receipt/state; digest collapses draft digest to draft; dry-run and marker system axes vary

- Trigger Path: Equivalent plain, Markdown, checklist, correction, synthesis, and paraphrase prompts through greenfield propose and sealed semantic snapshot

- Ownership: Domain Intelligence prompt custody, canonical intent recovery, actor/boundary projection, and typed system-axis derivation

- Timeline: Captured after all 24 cases passed individually but aggregate adjudication isolated 16 real product findings.

- Blast Radius: Greenfield proposals where equivalent intent is expressed across supported input styles

- SLO/SLA Impact: Delivery SLO impact: replacement holdout and release readiness blocked; no production outage

- Data Risk: Domain risk: semantic ownership and state facts can drift before confirmation. Delivery risk: release blocker. Operational risk: misleading proposals. No committed customer data loss occurred.

- Security/Compliance: Policy/safety impact: fail-closed release gate prevented shipping; no privacy or access-control execution occurred. Source custody and no-invention invariants remain mandatory.

- Invariant Violated: Equivalent source facts must compile to stable typed actor, action, state, result, dependency, constraint, and component axes before rendering

- Root Cause: Product meaning is still inferred by overlapping regex, token-set,
  scoring, and prose-recomposition paths. Those paths independently decide
  actor ownership, action units, state transitions, visible outputs,
  dependencies, constraints, and system axes. Moving individual rules into
  smaller files did not establish one semantic authority; equivalent evidence
  therefore takes different interpretation paths and later renderers reparse
  the resulting prose again.

- Solution: The active host authors a schema-constrained, source-cited Semantic
  Intent packet; `odylith greenfield semantic-intent-schema` exposes the exact
  contract. Deterministic code validates citations, graph references, polarity,
  completeness, operating limits, hashes, and transaction laws but never
  infers product meaning from prose. Material uncertainty asks one focused
  question. Independent model critique remains advisory and cannot rewrite the
  packet. Seal the verified graph into Product Intent authority v7, project
  governance from fact ids and relation coordinates, and validate once without
  a semantic repair loop. Delete the losing regex, score, and downstream
  prose-reparse paths as their final compatibility callers move; keep
  post-confirm publication model-free and byte-exact.

- Rollback/Forward Fix: Forward fix pre-confirm compiler only; post-confirm commit-only runtime remains unchanged.

- Verification: Exact paired canonical-fact tests for handoff, marker, packet, digest, accent, and dry-run groups; relevant workflow, canonical, semantic, component, transaction-boundary suites; retained-result issue adjudication before a full installed rerun.

- Prevention: Govern this work by outcome-anchored, mechanism-adaptive
  convergence: fixed consumer and safety outcomes, provisional mechanisms,
  explicit replacement triggers, bounded comparisons, falsifiable predictions,
  and deletion of the losing path. Make metamorphic Semantic Intent graph equality a first-class
  regression in addition to product-copy quality, exact source-citation
  custody, transaction laws, model-profile coverage, latency/cost budgets, and
  accepted-atom presence. Structurally fail if a post-IR consumer imports a
  semantic prose parser or if the retired interpretation owners regain a live
  Greenfield propose call site.

- Agent Guardrails: No case IDs, fixture phrase lists, title-specific repairs, evaluator masking of real drift, gate weakening, post-confirm repair, or untouched holdout access.

- Preflight Checks: Post-confirm runtime fingerprint must remain unchanged; evaluator false positives must be separated before product proof.

- Regression Tests Added: Exact paired canonical intent tests for equivalent plain, reordered Markdown, correction, checklist, synthesis, and pronoun paraphrase inputs
